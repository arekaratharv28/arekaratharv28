## 🚀 Featured Engineering Projects

### 🏥 Healthcare & Bio-AI
*   **Microvascular Ischemic Stroke Detection System:** Architected a three-stream multimodal framework using PyTorch to fuse deep retinal biomarkers, geometric vascular biomarkers, and demographic risk factors. Leveraged RETFound transfer learning (across datasets like BRSET and EyePACS) and deployed Grad-CAM heatmaps to ensure clinical explainability and defect-free feature isolation.
*   **Bio-Inspired SNN for ADHD Attention Dynamics:** Modeled ADHD attention dynamics using cortical modules and surrogate-gradient learning via SuperSpike and Backpropagation Through Time (BPTT). Designed cognitive biomarkers like the Attention Collapse Index (ACI) to validate pharmacological interventions.
*   **Retinal Vessel Segmentation Pipeline:** Built deep learning workflows utilizing U-Net and Attention U-Net architectures for accurate medical image understanding and mask quality checks.

### 🧠 Generative AI & NLP
*   **Local Multimodal RAG Research Pipeline:** Engineered a localized RAG system via LangChain, Qwen3, LLaVA, and ChromaDB to securely extract text, tables, and equations from complex research PDFs using local RTX 4080 execution.
*   **AI My Buddy Media Pipeline:** Automated a generative media production pipeline orchestrating HunyuanVideo-Avatar through ComfyUI and quantized Llama 3 to synthesize complete animated episodes from AI-generated scripts.

### ⚙️ Predictive Analytics & Backend Systems
*   **Insurance Premium Forecasting:** Developed an ensemble regression pipeline processing 950,000+ records using Optuna-optimized LightGBM, XGBoost, and CatBoost models to predict premiums with high accuracy.
*   **Geospatial Traffic Simulator:** Built an Android app (Kotlin/Java) integrating the TomTom Routing API to simulate dynamic velocity matrices and realistic Mumbai traffic conditions.
*   **Secure Assessment Platform:** Engineered a scalable Python/REST API backend with strict session management and automated stress-testing scripts for a high-concurrency proctoring platform.
